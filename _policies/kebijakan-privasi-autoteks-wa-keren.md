## 1. Pendahuluan

Work From Cafe ("kami") mengembangkan aplikasi AutoTeks WA Keren ("Aplikasi"). Kebijakan Privasi ini menjelaskan bagaimana kami memperlakukan data ketika Anda menggunakan Aplikasi.

Aplikasi ini dirancang **offline-first** — seluruh fitur inti (generator caption, generator font estetik) berjalan sepenuhnya di perangkat Anda tanpa mengirim data ke server kami, karena kami memang tidak mengoperasikan server backend untuk fitur tersebut.

Dengan menggunakan Aplikasi, Anda menyetujui pengumpulan dan penggunaan informasi sesuai dengan kebijakan ini.

## 2. Data yang Kami Kumpulkan

### 2.1 Data yang TIDAK kami kumpulkan
- Kami **tidak** meminta atau menyimpan nama, email, nomor telepon, atau informasi identitas pribadi lainnya.
- Kami **tidak** memerlukan pembuatan akun atau login untuk menggunakan Aplikasi.
- Teks yang Anda ketik atau caption yang Anda buat di dalam Aplikasi **disimpan hanya secara lokal** di perangkat Anda (menggunakan penyimpanan database lokal) dan tidak dikirim ke server kami.

### 2.2 Data yang dikumpulkan pihak ketiga (Iklan)
Aplikasi ini menggunakan layanan iklan **Google AdMob** untuk menampilkan iklan (banner dan interstitial) sebagai sumber pendanaan agar Aplikasi dapat terus dikembangkan secara gratis. Google AdMob dapat mengumpulkan data berikut secara otomatis melalui SDK-nya:

- Advertising ID (Google Advertising ID / GAID)
- Informasi perangkat (model, sistem operasi, bahasa)
- Data penggunaan aplikasi dan interaksi dengan iklan
- Alamat IP (untuk perkiraan lokasi umum, bukan lokasi presisi)

Data ini dikumpulkan dan diproses oleh Google sesuai dengan [Kebijakan Privasi Google](https://policies.google.com/privacy). Kami tidak memiliki akses langsung ke data mentah yang dikumpulkan Google dari perangkat Anda; kami hanya menerima laporan performa iklan secara agregat.

Anda dapat membatasi personalisasi iklan melalui pengaturan perangkat Anda:
- **Android:** Setelan > Google > Iklan > Nonaktifkan personalisasi iklan (atau "Reset advertising ID")

## 3. Izin Aplikasi (Permissions)

Aplikasi meminta izin berikut, hanya untuk fungsi yang benar-benar diperlukan:

| Izin | Tujuan |
|---|---|
| `INTERNET` | Diperlukan agar Google AdMob dapat memuat dan menampilkan iklan |
| `ACCESS_NETWORK_STATE` | Digunakan oleh SDK AdMob untuk memeriksa ketersediaan koneksi sebelum memuat iklan |

Aplikasi **tidak** meminta izin akses kamera, mikrofon, kontak, lokasi presisi, penyimpanan file di luar direktori aplikasi, atau izin sensitif lainnya.

## 4. Penyimpanan Data Lokal

Caption favorit, riwayat teks, dan preferensi yang Anda buat di dalam Aplikasi disimpan menggunakan database lokal (Room/SQLite) di perangkat Anda. Data ini:
- Tidak disinkronkan ke server mana pun milik kami.
- Akan terhapus otomatis jika Anda menghapus data Aplikasi atau meng-uninstall Aplikasi dari perangkat.
- Sepenuhnya berada di bawah kendali Anda.

## 5. Keamanan Data

Karena Aplikasi tidak mengirim data pribadi ke server kami, risiko kebocoran data pengguna dari sisi kami sangat minim. Untuk data yang diproses oleh pihak ketiga (Google AdMob), keamanan data tunduk pada praktik keamanan Google.

## 6. Privasi Anak-Anak

Aplikasi ini tidak ditujukan secara khusus untuk anak-anak di bawah 13 tahun dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak. Jika Anda adalah orang tua/wali dan mengetahui anak Anda telah memberikan data pribadi kepada kami tanpa persetujuan, silakan hubungi kami melalui kontak di bawah agar dapat kami tindak lanjuti.

## 7. Tautan ke Pihak Ketiga

Aplikasi mungkin menampilkan iklan yang mengarahkan Anda ke aplikasi atau situs web pihak ketiga. Kami tidak bertanggung jawab atas praktik privasi atau konten dari situs/aplikasi pihak ketiga tersebut. Kami menyarankan Anda membaca kebijakan privasi masing-masing pihak ketiga yang Anda kunjungi.

## 8. Perubahan pada Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diinformasikan dengan memperbarui tanggal "Terakhir diperbarui" di bagian atas halaman ini. Anda disarankan untuk meninjau halaman ini secara berkala.

## 9. Persetujuan Anda

Dengan mengunduh dan menggunakan Aplikasi AutoTeks WA Keren, Anda menyatakan telah membaca dan menyetujui Kebijakan Privasi ini.
